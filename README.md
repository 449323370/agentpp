# Agent++

## 让 Codex 式编码工作流支持国产模型与微信远程协作

Agent++ 是 TKEN 面向 Windows 的 AI 编码工作台：把项目理解、文件修改、命令执行、结果检查、插件和对话放进一个可持续的桌面工作流。它适合希望使用 Codex 类真实编码体验，同时需要国产模型、微信连接和更低总订阅成本的开发者。

> Agent++ 是独立的 Windows 客户端，不修改 OpenAI 官方 Codex；它把 Codex 式工作流扩展到更多模型和远程协作场景。

## 为什么选择 Agent++

- **一个 Key 调主流模型**：在同一账户和分组中切换 GPT、DeepSeek、GLM、Kimi、MiniMax 等主流模型，按任务选择能力、速度和成本。
- **Codex 平替式项目工作流**：围绕真实项目理解代码、修改文件、运行命令、检查结果，不只是打开一个聊天窗口。
- **让编码工作流连接微信**：完成微信连接后，可在支持的账户和客户端能力范围内远程关注任务状态、处理协作场景，让电脑前的编码工作延伸到手机端。
- **国产模型覆盖**：减少在多个客户端之间切换和重复配置，具体模型以当前账户服务目录为准。
- **价格优势**：一套桌面工作流统一管理模型与账户，减少重复购买多套客户端或订阅；实际价格、余额和可用模型以当前账户服务目录为准。
- **插件工作区**：把浏览器、设计、文档和开发工具接入同一个任务上下文。

## 首次使用

1. 安装并启动 Agent++，检查左下角账户和余额状态。
2. 首次使用选择“领取免费体验”，已有账户选择“连接已有密钥”。
3. 在“分组与密钥”中保存已开通服务的 Key。
4. 选择当前分组支持的模型，发送一条简短消息验证连接。
5. 完成微信连接后，按需使用远程协作能力；插件可从插件页安装。

完整教程：[Agent++ 使用帮助](https://www.tken.shop/agentpp-help)

## 安全与反馈

Key、Cookie、验证码和支付信息不要分享。模型能力、价格、余额和微信远程能力以当前账户授权及服务目录为准；模型不可用时，请从分组显示的模型列表选择，不要自行拼接模型名。
