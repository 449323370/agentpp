# Agent++

## 把 Codex 的编码能力，装进你的日常工作流

Agent++ 是 TKEN 提供的 Windows 桌面 AI 编码工作台。它把 GPT 与 DeepSeek、GLM、Kimi、MiniMax 等当前服务目录中的模型集中到一个客户端里，用一个分组 Key 连接当前账号已授权的模型，并把项目、文件、命令、插件和对话放进同一条可执行的工作流。

它不是只能问答的聊天窗口：你可以围绕真实项目理解代码、修改文件、运行命令、检查结果，再把一次对话推进到可以交付的结果。

> 本仓库用于发布 Agent++ Windows 桌面安装包和版本说明。核心客户端源码不包含在本仓库中，本仓库也不代表一个开源代码项目。

## 主要能力

- **真实项目工作流**：围绕项目文件进行代码理解、修改、命令执行和结果检查。
- **一个 Key，多种模型**：配置一次分组密钥，按任务切换 GPT 或国产模型；可用模型以当前账号授权和服务目录为准。
- **插件工作区**：把浏览器、设计、文档和开发工具等插件带进当前编码任务。
- **微信登录与账户中心**：统一管理注册、账户连接、绑定状态、订阅、充值、分组和密钥。
- **桌面端持续更新**：发布包带有校验信息，客户端更新链路会校验版本、大小和 SHA-256 后再执行安装。

## 从登录到第一次成功使用

1. 安装并打开 Agent++，先确认左下角账户状态和余额信息正常。
2. 打开左下角的 **账户**，首次使用选择 **领取免费体验**，已有账户选择 **连接已有密钥**。
3. 在账户中心确认账户、绑定状态和服务信息；需要时在 **充值与付款** 中完成充值或订阅。
4. 打开 **分组与密钥**，选择已开通的服务并保存分组 Key。当前密钥只用于当前桌面端连接，不要公开。
5. 回到对话窗口，在模型菜单中选择当前分组明确支持的模型，发送一条简短消息确认连接。
6. 点击左侧 **插件**，检查已安装插件或按页面提示安装需要的公开插件，再回到对话继续工作。

## 使用建议

- 模型不可用时，回到模型列表选择当前分组显示的名称，不要自行拼接或改写模型 ID。
- Key 无法连接时，检查是否多复制了空格，并确认 Key 属于当前账号和分组。
- 余额未更新时，先确认支付结果，再刷新账户；不要重复提交同一笔订单。
- 插件安装后没有显示时，刷新插件页并确认它出现在已安装区域。
- 更换账号或设备前，先确认账户中心的账号和微信绑定状态正确。

## 常见问题

**账户中心打不开**  
确认已经登录，刷新客户端后重试；仍无法打开时，请在 TKEN 帮助页反馈具体页面和版本号。

**模型列表为空或模型不可用**  
模型、能力和可用范围取决于当前服务目录和账户授权。请先确认分组 Key 已保存，再选择该分组显示的模型。

**第一次使用从哪里开始**  
建议按“账户连接 → 分组 Key → 模型选择 → 简短测试消息 → 插件”的顺序完成，不需要为每个模型重复配置。
