# Agent++## 开放模型接口与国产模型工作台Agent++ 是 TKEN 面向 Windows 的 AI 编码工作台，把项目理解、文件修改、命令执行、结果检查、插件和对话放进一条可持续的桌面工作流。它是独立客户端，不修改 OpenAI 官方 Codex。> Agent++ 通过账户服务与兼容 OpenAI 风格的外部接口，把 GPT、国产模型和自有模型连接到同一个真实项目工作流中。## 核心能力- **国产模型**：支持 DeepSeek、GLM、通义千问、MiniMax、百度文心/千帆等服务目录中的可用模型。- **开放模型接口**：在“设置 -> 个人 -> 模型连接”中添加 Base URL 和 API Key，获取模型列表，按可用性测试筛选，测试所选模型后再保存。- **同一工作区切换模型**：按任务选择速度、能力和成本；外部渠道可保留自己的模型 ID 与协议设置。- **不必额外翻墙使用已授权 GPT**：通过 TKEN 账户/中转服务，在中国大陆网络环境下使用服务端已开放的 GPT 模型。实际可用性取决于账户授权、服务端状态、网络和上游政策；这不是绕过第三方地区限制的承诺。- **Codex 式项目工作流**：理解真实项目、修改文件、运行命令、检查结果，不只是聊天问答。- **微信远程协作**：在支持的账户和客户端能力范围内关注任务状态，让编码工作延伸到手机端。- **插件工作区**：把浏览器、设计、文档和开发工具接入同一个任务上下文。## V132.0.0 下载- [GitHub Release](https://github.com/449323370/agentpp/releases/tag/v132.0.0)- [官方下载镜像](https://download.tken.shop/agentpp/agentpp-V132-Final-Windows-Setup-20260806.exe)- [官方下载别名](https://download.tken.shop/agentpp/agent++.exe?v=132.0.0)- 文件：agentpp-V132-Final-Windows-Setup-20260806.exe- 大小：645,077,998 bytes- SHA-256：F5282CA2DA7C0DC23BE75E59848C2F08745CDC0E9ED2855213E931F02FEFB97C下载后建议先核对 SHA-256，再运行安装程序。GitHub 与官方下载镜像是两个独立分发入口；下载链接本身不代表客户端已经自动安装更新。## 首次使用1. 安装并启动 Agent++。2. 首次使用选择“领取免费体验”，已有账户选择“连接已有密钥”。3. 在“分组与密钥”中保存已开通服务的 Key，选择当前分组支持的模型并发送一条短消息。4. 如需外部模型，进入“设置 -> 个人 -> 模型连接”，添加渠道、获取模型、测试所选模型，再保存。5. 按需完成微信连接或安装插件。完整教程：[Agent++ 使用帮助](https://www.tken.shop/agentpp-help)## 模型与安全边界模型、能力、价格、余额和微信远程能力以当前账户授权与服务目录为准；模型不可用时，请从已验证的模型列表选择。Key、Cookie、验证码和支付信息不要分享。只把 API Key 输入到你信任的渠道；客户端不会把外部渠道 Key 写入 TKEN 账户凭据或发布包。本仓库用于发布 Windows 安装包和版本说明，核心客户端源码不包含在仓库中。问题请提交到 [Issues](https://github.com/449323370/agentpp/issues)，只提供版本号、复现步骤和不含隐私的错误现象。
